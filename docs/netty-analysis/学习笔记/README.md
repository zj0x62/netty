# 学习笔记

每完成一个阅读任务（2.x），在这里新增一篇"一页笔记"。写代码任务（1.x / 3.x）不强制笔记，但关键设计决策建议记录。

## 命名规范

`阶段X-周Y-主题.md`，示例：

- `阶段2-周5-bytebuf.md`
- `阶段2-周7-server-accept.md`

## 一页笔记模板

直接复制 [模板.md](模板.md) 使用，内容字段：

| 字段 | 说明 |
|------|------|
| 机制一句话 | 是什么 + 解决什么问题 |
| 关键类/行号 | 本仓库 4.2.17.Final-SNAPSHOT 为准 |
| 对应我的坑 | 第一段/项目里踩过的对应问题 |
| 4.2 特有 | 与 4.1 的差异，若无则写"无" |
| 自测答案 | 对应任务的完成定义问题及答案 |

## 使用规则

1. 完成一个阅读任务后，新增一篇笔记，并在 [学习进度.md](../学习进度.md) 勾选对应任务。
2. 笔记是知识沉淀，只增不改；如需修正，在文末"修订记录"追加。
3. 笔记中引用行号时，注明仓库版本（4.2.17.Final-SNAPSHOT），避免版本漂移。
