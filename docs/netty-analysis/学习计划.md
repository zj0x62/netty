# Netty 4.2 学习计划（初学者 → 网络/中间件方向）

> 定稿日期：2026-08-04
> 时长：8~10 周，工作日每天 1~2 小时 + 周末加量
> 起点：Java 业务开发可用，无 NIO/网络编程经验
> 方向：网络/中间件/RPC

## 一、总目标

以 Netty 4.2 为素材，从零建立网络编程能力，最终交付一个可运行的迷你 RPC 雏形。

**唯一的成功标准**：能够独立讲清"一次请求从 client 发出到 server 响应，经过了哪些线程、哪些对象、哪些 Buffer"。

## 二、三条基本原则

1. **先写 → 再读 → 最后再写**：动手踩坑在前，源码阅读在后，动手收尾。
2. **主线 4.2，以仓库源码为准**：本仓库 + [docs/netty-analysis](README.md) 文档构成自洽的 4.2 世界；外部资料（博客、面试题多为 4.1）只作补充，遇到冲突以源码为准。
3. **做透一个，好过做烂两个**：每一段都有明确验收标准，不达标不进入下一段。

## 三、三段总览

| 阶段 | 周期 | 主题 | 方式 | 验收 |
|------|------|------|------|------|
| 第一段 | 第 1~3 周 | Java NIO 基础 | 写 | 阻塞版 + NIO 版 echo 服务器，100+ 并发不丢数据，代码审查通过 |

## 四、第一段：NIO 基础期（第 1~3 周）——写

**任务 1.5 观察阻塞版的问题**
