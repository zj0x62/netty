## 更新规则（快速版；完整流程见 学习系统操作手册.md）

1. **接续四步**：读接续块 → 解答待解答问题 → 按会话类型执行 → 结束更新接续块
2. **自动勾选**：仅限有证据的任务（笔记文件/代码产物/审查记录），证据写入记录表，对话中即时说明
3. **边界**：计划内容只有用户能改；agent 只更新状态区、勾选有证据任务、新增笔记
4. **Checkpoint**：每周对账，修正漂移，重排本周任务，结果记录到记录表
5. **一致性**：发现文档不一致，当场修并留痕，或记入待解答问题
